**正文**

给手上这台三星 NX500 写的改装固件 Metol 更新到 1.15.9 了 📷

这台机器 2015 年出厂，停产很多年，但底子是真的好——2800 万像素 APS-C，
机身比现在很多微单还小。缺点是原厂 App 早就停止维护，传张图费半天劲。

所以我自己写了一套跑在 SD 卡上的固件补丁，不刷机、不动原厂固件，
插卡就能用，拔卡就恢复原样。

**这次更新了三件事：**

**① 菜单终于改名了**
以前每次打开菜单，左上角写着 `NX-KS / 菜单`——那是我早期借用的上游项目名。
现在改成 `Metol / 菜单`，跟项目名对上了。

**② 视频设置终于集中到一页**
以前视频相关的设置散在两个地方：分辨率在一个页面，码率在另一个页面，
V-Log 曲线又藏在"实用功能"里。现在全部收到主页新增的「视频功能」页，
按"分辨率 → 码率 → 曲线"排好：

- 分辨率：4K 全宽 24p / 4K 原生 30p / 2.5K / 裁切 80%
- 视频码率
- V-Log 曲线
- 批量录制

（4K 全宽那条还在研究阶段，画面更广但会掉帧，日常拍建议用 2.5K 或 4K 原生）

**③ 手机传图，不用装 App 了**
这是最实用的一条。

**方法一：局域网（推荐，我天天用）**
1. 相机按一下 WiFi 键，连上家里路由器
2. 手机连同一个路由器
3. 相机菜单 → 系统设置 → **局域网相册**
4. 屏幕上会弹出一串地址，比如 `http://192.168.1.23/`
5. 手机浏览器打开那个地址——就是相册，点开照片能下原图

不用装任何 App，不用注册，地址每次开机可能会变，所以做成"点一下就弹出来"。

**方法二：相机自己发热点**
系统设置 → 相机热点 → 选 5G 或 2.4G，相机会把自己变成一个 WiFi，
手机连上之后浏览器开 `http://192.168.49.1/`。

这条我还在打通最后一环：射频部分（5G 信道、驱动模块）全都验证通过了，
但相机原厂那个"热点管理服务"在 1.12 固件上没被唤醒，所以热点最后一步起不来。
先把入口留着，通了就能用。

**关于这个项目**

- 完全开源，AGPL-3.0
- 不刷机、不改原厂固件，全部跑在 SD 卡 + 机身一个可写分区里
- 卸载就是菜单里点一下
- 上游是社区的 `nx500_nx1_modding`，我在此基础上加了自己的东西

GitHub 搜 `WApaperplane/NX500-metol`，
release 里下 `Metol-1.15.9.zip`（中文）或 `-EN.zip`（英文），解压到 SD 卡根目录，
插卡开机，屏幕提示安装完成就自动重启了。

⚠️ 提醒：改装有风险，装之前把卡里照片备份好，原厂固件也留一份。
