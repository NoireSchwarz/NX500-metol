# Metol 1.15.9

> 2026-11-22 · Menu title renamed to Metol; new "Video" page; two ways to pull photos off the camera

## What's new

### 1. Menu title: NX-KS → Metol

The on-screen header still said `NX-KS / Menu`. It now says `Metol / Menu` (recompiled `nxui.arm`).
Both the CN and EN packages.

### 2. New "Video" page on the main menu

Video-related items used to be mixed into "Custom Func." together with HDR / zoom / LUT.
They now live on their own page, ordered **resolution → bitrate → frame rate / curve**:

- **Resolution** → its own sub-page, four presets plus the upstream resolution-mapping entry
  - `4K Full 24p` — full-width sensor readout at UHD 24p. Wider field of view than native UHD;
    frame-drop issue still open, research status.
  - `4K Native 30p` — back to the stock output mapping
  - `2.5K Output` — 2560×1440
  - `Crop 80% 30p`
- **Video Bitrate** → stock five presets
- **V-Log Curve** → camera-level gamma, moved here from "Custom Func."
- **Batch Rec** → stock

"Custom Func." now only holds static features: remote save / ZoomZoom / HDR / LUT / version / camcorder.

### 3. Two ways to pull photos, under Settings

- **LAN Album** — tap it and the camera pops `[ http://192.168.x.x/ ]` on screen.
  Camera joins your router, phone joins the same router, open that URL. Full-size downloads work.
  **Tested and working.**
- **Camera Hotspot** — the camera broadcasts its own AP: `5 GHz` / `2.4 GHz` / `Hotspot Off`.
  Connect your phone to it and open `http://192.168.49.1/`.

The hotspot path is fully implemented: baseline check → band-enable word
(`/dev/mem 0x85440068`) → swap in `cfg80211-cn-low5g.ko` (insmod from `/tmp`, on-disk module
untouched) → bind-mount over `/usr/sbin/hostapd`. In practice it stalls because the stock
`mobileap-agent` is never activated by `org.tizen.tethering` on this unit. Details in
`docs/current/MIGRATION_FROM_NXSCHWARZ_2026-11-22.md`. The LAN path is unaffected.

### 4. Fixes

- The `chmod` fallback loop in `install.sh` only covered `nx-rc/*` one level deep, so
  `nx-rc/wifi/bin/` and `nx-rc/video/bin/` never got the executable bit — symptoms were
  "installed but nothing happens when tapped".
- The main menu is a **generated artifact**: `gen_menu.sh` renders `gui_tpl.NX500` into
  `gui_ini.NX500` on every open. Editing `gui_ini` only works once. This release edits the template.

## Install

Same as before: extract `Metol-1.15.9-EN.zip` to the SD card root → insert → "Install complete"
→ auto reboot.

**Note**: `cp -ar` overwrites but never deletes, and `scripts/` on the SD card is the master copy.
If you update manually, put the new files into the card's `scripts/` too, otherwise the next
install reverts everything.
