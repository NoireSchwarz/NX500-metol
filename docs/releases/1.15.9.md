# Metol 1.15.9

> 2026-11-22 · 相机菜单标题改为 Metol，新增「视频功能」页与两条传图链路

## 这一版做了什么

### 1. 菜单标题：NX-KS → Metol

相机屏上那个「NX-KS / 菜单」一直没跟着改名。这一版把 `nxui.c` 里的标题换成
`Metol / 菜单`，二进制重编。中文包、英文包都是。

### 2. 主页新增「视频功能」页

原来的「实用功能」里掺着视频相关的东西（视频码率、分辨率修改、批量录制、V-Log），
跟 HDR / 变焦 / LUT 混在一页。现在整出一个独立的分页，按**分辨率 → 码率 → 帧率/曲线**
的顺序排：

- **分辨率** → 独立子页，四个档位 + 上游的分辨率映射入口
  - `4K 全宽 24p`（全宽读出 + UHD 24p，画角比原生 UHD 宽；掉帧问题仍在，研究态）
  - `4K 原生 30p`（回原厂输出映射）
  - `2.5K 输出`（2560×1440）
  - `裁切80% 30p`
- **视频码率** →（上游五档码率）
- **V-Log 曲线** →（相机级 gamma，从「实用功能」搬过来）
- **批量录制** →（上游）

「实用功能」现在只剩静态功能：远程保存 / 变焦缩放 / HDR / LUT 滤镜 / 版本 / 摄像模式。

### 3. 系统设置里两条传图链路

- **局域网相册**：点一下，屏幕弹出当前相册地址 `[ http://192.168.x.x/ ]`。
  相机连路由器，手机也连同一个路由器，打开那个地址就是相册（点开有原图下载）。
  **这条已实测可用。**
- **相机热点**：相机自己发热点，分 `5 GHz` / `2.4 GHz` / `关闭热点`。
  热点起来后屏幕上会弹一次 `[ http://192.168.x.x/ ]`，手机连上相机热点后打开这个地址。
  **两条都已实测可用。**

底层链路是：基线检查 → 频段使能字（`/dev/mem 0x85440068`）→ 换上 `cfg80211-cn-low5g.ko`
（从 `/tmp` insmod，不动盘上模块）→ 劫持 `/usr/sbin/hostapd` 改配置成 CH48 / HT40-minus。
详见 `docs/current/MIGRATION_FROM_NXSCHWARZ_2026-11-22.md`。

### 4. 修掉的坑

- `install.sh` 的 chmod 兜底循环原来只盖到 `nx-rc/*` 一层，`nx-rc/wifi/bin/`、
  `nx-rc/video/bin/` 里的可执行位不会被补 —— 表现是「装完点了没反应」。
- 主菜单是 `gen_menu.sh` 用 `gui_tpl.NX500` 渲染出来的**产物**（`gui_ini.NX500`），
  改 `gui_ini` 只在当前这一次有效。这一版改的是模板。

## 装法

和其他版本一样：`Metol-1.15.9.zip` 解压到 SD 卡根目录 → 插卡 → 屏上「安装完成」→ 自动重启。

**注意**：`cp -ar` 只覆盖不删除，SD 卡上的 `scripts/` 是母本。手动更新时要把新文件
拷进 SD 卡的 `scripts/`，否则下次装机还是旧版。

## 已知状态

- 局域网相册：可用
- 相机热点（5 GHz / 2.4 GHz）：可用（起热点前脚本会自动激活原厂 tethering 服务）
- 4K 全宽 24p：画角成立，掉帧未解，属研究态；想稳就用 `2.5K 输出` 或 `4K 原生 30p`
